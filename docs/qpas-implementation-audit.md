# Q-PAS 实现审计：代码 vs 论文 Algorithm 3 逐条核对

> **结论**：Q-PAS 的算法骨架——状态划分、奖励定义、ε-greedy 极性、Q 更新、
> 每代调用一次、与 VNS/MOEA/D 的相对顺序——**现在与论文 Algorithm 3 一致**。
> 全文唯一的"主动偏离论文"是 Q 更新公式，而论文那一处公式是排版错误
> （字面形式在数学上无解），因此该偏离是必要修正。
>
> 真正剩下的问题不在公式，在三处实现瑕疵与论文自身的 6 处印刷错误/内部矛盾。
> 其中最实质的一条：**论文式 (14) 的 CV 没有规定归一化，导致状态空间被大量纲
> 目标独占**——Mk10 上 `f2` 占 `CV²` 的 96.5%，makespan 对状态完全"隐形"。
>
> 复现命令：`python scripts/t_leverage_analysis.py --lab_json logs/_mk10_lab.json`
> 审计脚本：`logs/_qpas_audit.py`（逐项输出见 `logs/_qpas_audit.txt`）

## 一、逐条核对表

论文依据：Algorithm 3（Q-PAS）、Algorithm 1（RMOEA/D 主循环）、
Section 4.5.2–4.5.5、式 (13)–(18)、Table 6 参数表。

| # | 论文要求 | 代码位置 | 判定 |
|---|---|---|---|
| 1 | `Q_table (4,4) ← 0`（Alg.3 line 1） | `qlearning.py: q_table = np.zeros((4,4))` | ✅ 一致 |
| 2 | 动作集 `T ∈ {5,10,15,20}`（§4.5.2、Table 6） | `actions=[5,10,15,20]` | ✅ 一致 |
| 3 | 4 个状态 = (ΔCV, ΔDV) 的 4 种符号组合（§4.5.3） | `get_state` 分支 | ✅ 一致 |
| 4 | `CV = sqrt(Σ_{y∈P} min_{x∈P*} dis²/\|P\|)`（式 14） | 到原点 (0,0) 的均方根距离 | ✅ 一致（`P*` 取理想点单点，符合"predefined reference point"） |
| 5 | `DV = Σ\|d_i − d̄\| / ((N−1)d̄)`（式 15） | 相邻点距离的变异系数 | ✅ 一致 |
| 6 | `ΔCV = CV_{i−1} − CV_i`（式 16） | `prev_cv - cv` | ✅ 一致 |
| 7 | `ΔDV = DV_i − DV_{i−1}`（Alg.3 line 11） | `dv - prev_dv` | ✅ 一致（式 17 印刷成 `DV_i − CV_{i−1}`，代码按 Alg.3 的正确形式） |
| 8 | `R = 10 if ΔDV>0 else 0`（式 18） | `10.0 if delta_dv > 0 else 0.0` | ✅ 一致 |
| 9 | ε-greedy **反向**：`if rand < ε → 取 max Q`（Alg.3 line 5–8、§4.5.5） | `if rng.rand() < epsilon: argmax` | ✅ 一致（曾写反，已修） |
| 10 | `Q(St,At) ← Q + α[R + γ(max Q(S',·) − Q)]`（式 13） | 标准 TD：`Q + α(R + γ·maxQ' − Q)` | ⚠️ **主动偏离**，见第二节（论文式字面发散） |
| 11 | 主循环顺序：VNS → 选 T → MOEA/D → 更新 Q（Alg.1 line 4–7） | `algorithm.py` Step 1→4、Q 更新在下一轮 | ✅ 一致 |
| 12 | 每代调用一次 Q-PAS | 每 `gen` 一次 `ql.step` | ✅ 一致 |
| 13 | 首次状态（Alg.3 line 1 `ΔCV←1, ΔDV←1`） | `state = 0` | ✅ 一致（论文 line 1 自相矛盾，见第四节） |

**语义核对（容易做错但做对了的地方）**：
`step(pf)` 接收的是**上一代 MOEA/D 产出的前沿**，内部用 `prev` 与 `cur` 的差算出
Δ，再去更新 `Q(prev_state, prev_action)`——即"动作 A 的效果由执行它之后的 PF
变化来评估"。这与 Alg.3 第 9–14 行（执行动作 → 取 PF → 算 Δ → 给奖励 →
更新 Q）严格对应，不是"先更新再用"的顺序错误。

## 二、唯一的主动偏离：Q 更新公式

论文式 (13) 与 Algorithm 3 第 14 行写的是：

```
Q(St,At) ← Q(St,At) + α[ R + γ·( max Q(St+1,At) − Q(St,At) ) ]
```

代码 `qlearning.py` 写的是标准 TD：

```
Q(s,a) ← Q(s,a) + α·( R + γ·max Q(s',·) − Q(s,a) )
```

差别在 `− Q(s,a)` 这一项在 γ 括号**内**还是**外**。数值模拟单个 (state, action)
被反复访问、每步奖励 R=10（α=0.4, γ=0.6）：

| 迭代次数 | 论文式字面 | 标准 TD（代码） |
|---:|---:|---:|
| 1 | 4.0000 | 4.0000 |
| 2 | 8.0000 | 7.3600 |
| 5 | 20.0000 | 14.5447 |
| 10 | 40.0000 | 20.6275 |
| 50 | 200.0000 | 24.9959 |
| 100 | 400.0000 | 25.0000 |
| 200 | 800.0000 | **25.0000** |

标准 TD 收敛到 `R/(1−γ) = 25`（Bellman 不动点）；论文式字面每步线性增长
`α·R = 4`，200 步就是 800，**没有不动点**。

严格证明：令 `Q = max Q'`（收敛时对 argmax 动作成立），论文式给出
`0 = αR + αγQ − αγQ = αR`，即要求 `R = 0`——与 R=10 矛盾。所以论文式 (13)
的字面形式在 `R > 0` 时不可能稳定，属于**括号错位**的排版错误。代码采用标准
TD 是唯一数学上成立的读法，也是所有 Q-learning 文献的写法。

> 这条不是"我们凑结果"，而是"论文算式无法执行"。复现者必须做这个修正，
> 且应在复现说明里显式记录。

## 三、一个实质的实现瑕疵：CV 未归一化

论文式 (14) 用**原始目标值**计算到参考点的距离，且**未规定归一化**。当两个目标
量纲悬殊时，CV 被大量纲目标独占。

在 Mk10 上一次 200 代实跑中直接测量：

```
mean(f1) =  356.321      mean(f2) = 1876.098
CV² 的贡献:  f1 ->   3.5%      f2 ->  96.5%
```

`f2`（总负载）独占 `CV²` 的 **96.5%**。由于状态只由 `ΔCV` 的**符号**决定，
`ΔCV` 的符号几乎就是"`f2` 是否改善"——**makespan 这个目标对 Q-PAS 的状态完全
隐形**。四个状态里实际只编码了两条信息（`f2` 方向 × `DV` 方向）。

把同一批前沿的两个目标拉回同一尺度（[0,1]）后重算状态序列：

```
与未归一化版本一致的状态数 = 110/199 = 55.3%
发生翻转的状态数          =  89/199 = 44.7%
```

**近一半的状态在一次纯尺度变换下改变了身份**。也就是说当前的状态划分不是
尺度不变的，它测量的是"在这个特定实例的目标量纲下"的方向。

这解释了为什么 Q-PAS 的信息量如此之低：不是 4 状态 × 4 动作的信息量，
而是**实际不足 2 状态 × 4 动作**，且其中一维（f1）被淹没。

### 处理方式

论文没有归一化，所以**默认行为必须保持不变**（复现优先）。新增一个论文之外的
可选开关：

```python
RMOEAD(..., ql_cv_normalize=True)     # 默认 False = 严格照论文式(14)
QLearningPAS(cv_normalize=True, hv_bounds=(lo, hi))
```

打开后 CV 先用 `hv_bounds`（缺省则用本代前沿范围）把两个目标归一到同一尺度，
使 CV 同时反映两个目标。回归测试 `TestQpasCVNormalization`（6 条）锁住
"默认不得偏离论文"与"打开后确实抹平尺度"两件事。

### 但修它并没有救回 Q-PAS（负面结果，如实记录）

Mk10、30 seeds、同一参考集（900 runs）下的对照：

| 臂 | CV 口径 | HV | vs T50（最优固定 T） |
|---|---|---:|---|
| `QPAS2_dv` | 论文（原始尺度） | 0.82740 | −0.01250 n.s. |
| `QPAS2_dv_cvnorm` | 归一化 | **0.82458** | −0.01532 n.s. |
| `QPAS2_hv_wide` | 论文（原始尺度） | **0.83590** | −0.00400 n.s. |
| `QPAS2_hv_wide_cvnorm` | 归一化 | 0.83091 | −0.00899 n.s. |

归一化**确实**改变了状态序列与学到的策略——T 使用分布从
`{5:27.1%, 10:24.7%, 15:22.9%, 20:25.3%}` 变成 `{5:23.2%, 10:26.2%, 15:26.9%, 20:23.7%}`
（更均匀），Q 表最大值从 15.0 升到 20.6——但 HV **没有改善，反而略降**。

所以必须把话分清楚：

- 「CV 未归一化」是**定义层面的瑕疵**，应当写进复现说明（因为 44.7% 的状态
  会在尺度变换下翻转，意味着状态语义依赖于目标量纲）；
- 但它**不是** Q-PAS 失效的原因。去掉它之后，Q-PAS 依然追不上一个固定的 `T=50`。

### 真正的原因：T 的收益曲线在 T=5 之外几乎是平的

```
T05  0.79367   <- 唯一的“坑”
T10  0.82309
T15  0.83734
T20  0.82773
T50  0.83990   <- 最优固定 T
T100 0.82463
```

排除 `T=5` 后，其余五档的极差只有 **0.0168**，而 run 间标准差是 **0.034 ~ 0.055**。
也就是说 T 的杠杆**几乎全部来自"别用 T=5"**，而不是"精确选到最优的 T"。
任何自适应选 T 的策略，相对一个合理默认值的最大可及收益都在 1 个标准差以内——
信噪比不足以产生可检测的效应。这解释了为什么 4 种奖励模式、6 组配置、
CV 归一化、乐观初始化全都测不出差异。

## 四、论文自身的问题清单

除了式 (13) 的括号错位（第二节），论文还有 5 处印刷错误或内部矛盾。列出它们
是因为**复现者不能照抄字面**，且这些地方会误导读者对 Q-PAS 的评价。

| # | 位置 | 问题 | 我们怎么处理 |
|---|---|---|---|
| 1 | 式 (13) / Alg.3 line 14 | 括号错位 → 迭代无不动点（第二节） | 用标准 TD |
| 2 | 式 (17) | 印成 `ΔDV = DV_i − CV_{i−1}`，应为 `DV_i − DV_{i−1}` | 按 Alg.3 line 11 的正确形式实现 |
| 3 | Alg.3 line 1 | 自相矛盾：既写 `ΔCV ← 1; ΔDV ← 1`（→ 状态 0），又写 `CV_{i-1}=CV_i=DV_{i-1}=DV_i=0`（→ 状态 3） | 取状态 0，与前者意图一致 |
| 4 | §4.5.5 末句 | "Q(St,At) in Q-table is updated by **Eq.(15)**"——式 (15) 是 DV 的定义，不是 Q 更新 | 按式 (13) 实现 |
| 5 | Alg.3 line 12 | "reward ... by **equation (20)**"——奖励定义在 §4.5.4 是式 (18)，文中没有式 (20) | 按式 (18) 实现 |
| 6 | §5.3 正文 vs Table 3 | 正文说 "If both CV and DV seldom increase, then **T = 5 or 10**"（即 State4），但 Table 3 的 State4 argmax 是 **T = 15**（2.9115 > 2.8471(T5) > 2.2838(T10)） | 无法处理：论文自相矛盾，只能如实标注 |

**Table 3 的可复现性问题**：该表 16 格中有 **6 格精确为 0**。按 Q-learning 更新，
任何被访问过且拿到奖励 10 的 `(s,a)` 都会立刻有 `Q ≥ α·10 = 4`，所以"精确 0"
只能意味着**从未被访问**。这张表记录的是"第一个恰好撞上奖励的臂"，不是每个
状态的最优动作。最大项 6.744 反推成功率仅 `6.744/25 = 0.27`。

我们同配置（Mk10 / seed 42 / 200 代）跑出的 Q 表：

```
         T=5       T=10      T=15      T=20    argmax
S0    7.6847    7.8177    0.0000    8.8847    T=20
S1    7.1549    5.5391    3.3350    3.1969    T=5
S2   10.3981    0.0000    4.5911    7.6259    T=5
S3    7.3106    6.4459    7.0194    5.8946    T=5
```

形态与论文同族（都被精确零主导），且 Q 值与 `10·P(ΔDV>0|s,a)/(1−γ)` 的估计
吻合（例：S2-T5 预测 11.90 / 实际 10.40；S0-T20 预测 8.57 / 实际 8.88）。
**这从实证上确认了 Q-PAS 本质上是"选那个最常改善 DV 的动作"**，而不是在
优化 HV。

> 结论：把"精确复现 Table 3 的取值"当作目标是没意义的——那张表只反映论文
> 那一次运行的访问顺序。

## 五、其余实现瑕疵

不影响已有结论，但应记录（都不构成"算错"）：

1. **Q-PAS 与主搜索共享 RNG**：`algorithm.py` 传的是 `self.rng`，而它同时驱动
   MIX3 初始化、交叉、变异、轮盘赌。Q-PAS 每代多消耗 1~2 次抽样，于是同 seed 下
   "Q-PAS 组"与"固定 T 组"的轨迹从第 1 代起就分叉——分叉原因不只是 T 不同。
   配对 Wilcoxon 仍然无偏，但方差被抬高：**被归因为"Q-PAS 噪声"的一部分，
   其实是 RNG 流差异**。给 Q-PAS 一个独立的 `RandomState(seed)` 是廉价的
   实验严谨性改进（不违反论文）。
2. **死变量 `is_first`**：`step()` 返回、`algorithm.py` 接收，但从未被使用。
3. **`q_init="optimistic"` 用固定种子** `RandomState(20240916)`：所有 run 共享
   同一张初始 Q 表，引入跨 run 相关性。
4. **`reward_mode="dv"` 硬编码 10.0**，未走 `w_dv` 参数（只有 `cv_dv` 模式用）。

## 六、结论

**Q-PAS 写得对不对？——核心算法逻辑是对的。**

- 13 条核对项中 12 条与论文一致；唯一的主动偏离（Q 更新公式）是论文排版错误
  下的必要修正，且是可证明的：论文式字面在 `R>0` 时没有不动点。
- 之前修掉的 3 个问题（HV 归一化口径、ε-greedy 极性、平局自锁）都是**真 bug**，
  现在都有回归测试锁定（`tests/test_refactor.py`，44 passed）。

**但"对"不等于"有效"。而且这次审计把无效的原因从"信息量不够"修正为更硬的
事实：这个决策变量本身没有足够的杠杆。**

原来的猜测与实测结果：

| 猜测 | 验证方式 | 结果 |
|---|---|---|
| 状态维度过低（CV 被 f2 独占） | 加 `cv_normalize` 开关，Mk10 × 30 seeds | **无效**，HV 略降（0.83590 → 0.83091） |
| 奖励设计不对 | 4 种奖励模式（`dv`/`cv_dv`/`hv`/`hv_cont`）两两对照 | **全部 n.s.** |
| 动作空间排除了 T=50 | `QPAS2_*_wide`（含 T=50） | 有改善（+0.013）但仍追不上固定 T=50（−0.004 n.s.） |
| 平局自锁 | `tie_break="random"` | **有效**（从显著劣于 T=50 变成打平） |

把 T 的收益曲线摊开看，根因就清楚了：**排除 T=5 之后，T 几乎不再是杠杆**
（五档极差 0.0168 vs run 间 σ 0.034~0.055）。所以问题不是"Q-PAS 学不到最优 T"，
而是"**最优 T 与任意合理 T 之间没有可检测的差距**"。

**由此得到的方向（与之前不同）**：

1. **不要再优化"选 T"**。把动作空间下界抬到 10（避开 T=5）就拿到了几乎全部收益，
   剩下的自适应空间在噪声量级以内。
2. **如果要保留 RL 组件，应换个决策变量**。实测真正的杠杆是局部搜索强度：
   `ls_trials` 从 1 提到 3 有 **+4.68% (p=3.5e-05\*\*\*)**，且只有在 `ls_trials=3`
   时"RL 引导选算子"相对"随机选算子"才显著（**+1.86%, p=0.045\***）。
   把 Q-PAS 的机制迁移到"选 `ls_trials`"或"选算子"上，比继续调 T 更有希望。
3. **隔离 Q-PAS 的 RNG**（第五节第 1 条），让每次消融比较真的只差一个变量。
